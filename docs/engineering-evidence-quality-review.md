## Source provenance and dependency boundaries

The matrix attributes the **linked implementation** to the repository, not every file in a historical tree. A Git commit and a passing test establish traceability, not copyright ownership or redistribution rights. Root licenses do not relicense external packages, vendor code or course material. The scope below was checked against current READMEs, tracked files, dependency declarations and notices; it is not a new file-by-file rights clearance.

| Repositories | Boundary relevant to a technical interview |
| --- | --- |
| Python Host | Repository application code; PyQt5 and pyserial are optional installed dependencies, not evidence of a connected device. |
| Embedded C/C++ and C51 Board | Linked practice modules and tests are the demonstrated work. Historical learning directories should not be presented as independently rights-cleared wholesale. |
| OTA and Cortex-M | Portable host modules are the demonstrated work. Vendor MCU libraries, boot chain and hardware drivers are outside the tested implementation. |
| FreeRTOS | Repository application and tests use the official V11.3.2 Kernel as a pinned Git submodule; see [notices](https://github.com/REliasCheng/FreeRTOS-Embedded-Lab/blob/e65cec6eb5f02fd6e9e8dd2cbf416ea4586d0510/THIRD_PARTY_NOTICES.md). The Kernel is not a repository-authored scheduler. |
| LVGL | Repository dashboard model/UI/tests use a pinned upstream LVGL v9.6.0 submodule and distribution SDL2; see [notices](https://github.com/REliasCheng/LVGL-Embedded-GUI-Lab/blob/1bc8ab0af33b78ebc00264df885913b39802cb6d/THIRD_PARTY_NOTICES.md). Widgets and renderer internals are upstream. |
| Wireless / IoT | Repository model and host adapter use installed libmosquitto and a local Mosquitto Broker. This is real Host TCP integration, not repository-authored MQTT transport or radio firmware. |
| ARM Linux | Repository userspace code uses Linux PTY and distribution cross tools/QEMU. The excluded vendor BSP, board kernel and RootFS are not credited as delivered work. |
| Robotics | Repository `offline_control/` and `tests_offline/` are separate from the attributed Apache-2.0 GenkiArm/LeRobot subtree; see [notices](https://github.com/REliasCheng/Embodied-Robotics-Arm-Lab/blob/b21e2f47bf82f3fbe623fa2343a8ac768a716173/THIRD_PARTY_NOTICES.md). Fake Bus tests do not execute the third-party motor runtime. |
| STC8, STC89 and BlueBridge | The linked portable cores, policies and SDCC target adapters are the demonstrated units. SDCC is an external tool. Legacy Keil/course/board material is not thereby validated or relicensed. |
| Foundations | Navigational documentation, without a software test claim. Referenced teaching/vendor material needs its own provenance review before reuse. |
