**Embedded Systems Developer**

## ⚙ What I Build

Firmware for 8051/STC and Cortex-M platforms, from register configuration to interrupt-driven control.

GPIO, timers, UART, I²C, SPI, ADC, DMA, display, storage, and sensor interfaces.
